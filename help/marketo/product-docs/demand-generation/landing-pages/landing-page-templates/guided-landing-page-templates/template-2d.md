# Plantilla 2D {#template-2d}

Haga clic con el botón derecho en [descargar plantilla 2D](https://51837-micrositemarketo.adobeio-static.net/lp-templates/template-2d.html) y seleccione **Guardar vínculo como...**

>[!NOTE]
>
>Puede encontrar los pasos completos para descargar e importar una plantilla [aquí](/help/marketo/product-docs/demand-generation/landing-pages/landing-page-templates/guided-landing-page-template-list.md#how-to-import){target="_blank"}.

![](assets/image2015-6-4-9-3a38-3a47.png)

Esta plantilla incluye el siguiente contenido:

* Un encabezado con logotipo y botón (opcional)
* Una sección principal

  * incluye una imagen de fondo a pantalla completa, encabezado, eslogan, lista con viñetas y formulario.

* Una sección del cuerpo con texto y sondeo (opcional)
* Pie de página (opcional)

**Haga clic con el botón derecho a continuación (y seleccione _Guardar vínculo como..._) para descargar esta plantilla:**
